# Как показать магазин на уроке

Магазин работает на компьютере учителя — без сервера и без ключей. Оплата, коды входа и Telegram в учебном режиме имитируются, но работает тот же код, что у настоящего магазина. Показ — через проектор с компьютера учителя: с компьютеров учеников по школьной сети этот запуск не открывается.

## Подготовка

**Один раз** — установка (нужны [Python 3.12+](https://www.python.org/downloads/) с галочкой «Add python.exe to PATH» и [Node.js 20+](https://nodejs.org/)):

```
scripts\setup.cmd
```

В конце она печатает логины и пароли сотрудников. Они же лежат в файле `backend\demo-accounts.txt` — в git он не попадает, не публикуйте его.

**Перед каждым уроком** — закройте окна магазина, если они открыты, и запустите:

```
scripts\reset-demo.cmd
scripts\start.cmd
```

- `reset-demo.cmd` делает магазин «как новый»: всё, что накликали на прошлом уроке, пропадает, история заказов снова заканчивается сегодняшним днём, таймеры не просрочены. Пароли остаются прежними.
- `start.cmd` открывает два окна — «Sovga — API» и «Sovga — витрина» — и сам открывает витрину и админку в браузере. Не закрывайте эти окна до конца урока.

## Кто есть кто

| Роль | Где | Вход | Что видно |
|---|---|---|---|
| Покупатель | витрина http://localhost:3000 | номер `90 111 01 01` … `90 111 01 12` или любой свой — код появится на экране | поиск, сравнение, корзина с подарком, оформление, оплата, статусы |
| Администратор | админка http://localhost:8000/admin | `admin` | всё, включая сотрудников и их права |
| Менеджер | админка | `manager` | каталог, цены, поставщики, склад, заказы, отчёт, «Имитация Telegram» |
| Оператор | админка → «Рабочее место оператора» | `operator` | очередь заказов с таймерами, сборка по IMEI, курьер, возвраты, гарантия |
| Бухгалтер | админка → «Выгрузка для бухгалтера» | `accountant` | Excel реализаций и возвратов, платежи |

**Каждую роль — в своём окне инкогнито** (или в другом браузере). Витрина и админка живут на одном `localhost`, и один браузер помнит только один вход: войдёте покупателем — админка попросит войти снова.

## Сценарий урока (около 40 минут)

1. **Витрина (5 мин).** Главная → поиск «айфон» (магазин понимает и так) → карточка iPhone 16 Pro: выбор памяти и цвета меняет цену, лента «Подарок до …». «Сравнить» его с Galaxy S25 Ultra. Переключите язык на узбекский.
2. **Покупка (10 мин).** «Купить» → в корзине подарок выбран сам → «Оформить заказ» → номер `90 111 01 01` → код уже на экране → адрес → «Картой онлайн» → «Оплатить через Payme» → страница «Учебная оплата» → «Оплатить». Второй заказ — «При получении»: он без оплаты сразу уходит на сборку.
3. **Заказ глазами магазина (10 мин).** В окне оператора — «Рабочее место оператора»: заказы по этапам с таймерами. Откройте заказ из «К сборке» → «Начать сборку» → IMEI подсказан под полем (на складе его «печатает» сканер) → галочка «проверен в UzIMEI» → «Добавить» → имя и телефон курьера → «Передать в доставку» → «Доставлен». Покупатель видит каждый шаг на странице заказа.
4. **Telegram (5 мин).** «Имитация Telegram»: чат «Менеджеры» — новые заказы и оплаты; чат поставщика — запрос «есть ли товар» с кнопками «Есть / Нет / Другая цена» (нажмите «Есть» — заказ из «Ждут ответа поставщика» перейдёт к оплате); чаты покупателей — статусы их заказов.
5. **Деньги и возвраты (5 мин).** Бухгалтер → «Выгрузка для бухгалтера» → Excel за месяц. Оператор → этап «Возвраты»: у заказа «Запрошен возврат» впишите IMEI из его состава (он на той же странице) → «Сверить и принять» → «Деньги возвращены».
6. **Итог (5 мин).** Как устроен код и какие задачи можно взять ученикам — в [CONTRIBUTING.md](../CONTRIBUTING.md).

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| Браузер не открылся, «Магазин не ответил за две минуты» | Ошибка — в окне «Sovga — API» или «Sovga — витрина». Часто магазин уже запущен в старых окнах: закройте все окна Sovga и запустите `start.cmd` снова |
| `reset-demo.cmd`: «Не удалось удалить базу» | Закройте окно «Sovga — API» и повторите |
| Админка просит войти снова | В этом браузере вошли покупателем — см. «Каждую роль — в своём окне» |
| «У вас уже есть заказ с оплатой при получении» | Правило магазина: один незавершённый такой заказ на покупателя. Отмените его на странице заказа или войдите другим номером |
| Красные таймеры «просрочен» | Магазин давно не сбрасывали — так оператор видит опоздания. Перед уроком — `reset-demo.cmd` |
| Забыли пароль | `backend\demo-accounts.txt`. Новые пароли — удалите этот файл и запустите `reset-demo.cmd` |
| Курс доллара 11 800 | Учебный. Настоящий курс ЦБ подтянет `scripts\jobs.cmd`, если есть интернет |
