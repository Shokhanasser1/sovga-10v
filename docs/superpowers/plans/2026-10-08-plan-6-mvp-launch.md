**Goal:** Закрыть пункты MVP (раздел 6 спецификации), которые не упираются во внешние договоры и ключи, и подготовить проект к запуску на сервере без Docker: настройки прода, инструкции, конфиги, проверка безопасности.

Не делаем, пока нет договора или ключа: рассрочка (договор с Uzum Nasiya / Alif), карта в адресе (ключ Yandex Maps), фискализация Click (их фискальный API и доступ), API службы доставки (служба не выбрана), нагрузочный тест k6 (нужен сервер, похожий на боевой).

## Global Constraints

Все ограничения Планов 1–5 действуют. Дополнительно:
- `manage.py check --deploy` при `DEBUG=false` — без предупреждений; в проде cookie только по HTTPS, HSTS, прокси-заголовок HTTPS только от nginx.
- Инструкции — для человека без опыта: Windows для разработки, Ubuntu-сервер для запуска; никаких секретов в репозитории.

## Задачи

### Task 1. Витрина: eSIM и вернувшийся покупатель
- Карточка: у модификации «Только eSIM» — предупреждение, что физическую SIM вставить нельзя.
- Заказ запоминает адрес покупателя; `GET /auth/me/` отдаёт последний адрес; оформление подставляет его.

### Task 2. Алерт маржи
- При оформлении заказа: маржа (выручка − себестоимость товаров и подарков по курсу заказа) ниже суммы минимальных маржей правил наценки → менеджерам «Заказ … — маржа N сум ниже минимума M».

### Task 3. Прайс поставщика через бот
- Поставщик присылает боту файл .xlsx/.csv (до 5 МБ) → импорт по колонкам из карточки поставщика → ответ: строк, сопоставлено, ждут сопоставления, с ошибками.

### Task 4. Подготовка к запуску
- Настройки прода (HTTPS-cookie, HSTS, `STATIC_ROOT`, логирование), `gunicorn`.
- `README.md`: что это, запуск на Windows по шагам, тесты, переменные окружения; `docs/deploy.md`: сервер Ubuntu — PostgreSQL, gunicorn, Next.js, nginx, systemd (сайт, витрина, бот), cron для `run_jobs`, бэкапы.
- `deploy/`: nginx, systemd, cron; `scripts/setup.cmd`, `scripts/start.cmd` для Windows.

### Task 5. Безопасность и итоговая проверка
- semgrep (Python, Django, TypeScript), `npm audit`, проверка зависимостей; исправить найденное.
- Полные тесты, сборка, e2e витрины.
