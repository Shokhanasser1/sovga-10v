# План 7. Учебный режим и открытый проект — план реализации

> Выполняется по задачам, каждая через TDD: тест → падает → код → проходит → коммит.

**Goal:** Проект открыт для всех и развивается учениками: он полностью работает без настоящих ключей — всё, что не настроено, имитируется так, чтобы были видны и работали те же пути кода, что с настоящими сервисами; запускается на любом бесплатном сервере.

**Решение (2026-10-08):** проект публичный и учебный; настоящие ключи, юрист и платный сервер пока не нужны. `DEMO_MODE=true` включает имитацию всего, что не настроено. Настоящий ключ, если задан, всегда главнее имитации.

## Global Constraints

Все ограничения Планов 1–6 действуют. Дополнительно:
- Имитация проходит через настоящие обработчики: оплата — через `payme.handle` и `click.prepare/complete` с тем же протоколом, что у провайдера; бот — через `dispatch.handle_update`; уведомления — через outbox.
- В учебном режиме на каждой странице витрины — плашка «Учебный магазин: оплата, SMS и Telegram — имитация, деньги не списываются». Страница имитации оплаты не повторяет оформление Payme / Click.
- Имитация оплаты доступна только владельцу заказа (сессия + CSRF) и только при `DEMO_MODE=true`; вебхуки провайдеров без ключей по-прежнему отклоняют всё.
- В репозитории нет секретов (история проверена 2026-10-08).

## Задачи

### Task 1. Учебный режим и имитация оплаты
- `DEMO_MODE`; `GET /api/v1/demo/` → `{demo}`; плашка на витрине.
- Без ключей провайдера в учебном режиме ссылка на оплату ведёт на страницу «Учебная оплата»: «Оплатить» (Payme: Check → Create → Perform; Click: Prepare → Complete), «Отказаться», для оплаченного через Payme — «Провайдер вернул деньги».

### Task 2. Код входа на экране
- Без Telegram Gateway / Eskiz в учебном режиме код показывается на странице входа.

### Task 3. Имитация Telegram
- Без токена бота в учебном режиме сообщения бота пишутся в базу; админка → «Имитация Telegram»: чаты менеджеров, поставщиков и покупателей, кнопки под сообщениями, ответ текстом от имени чата. Привязка покупателя и поставщика к учебным чатам — без ссылок t.me.

### Task 4. Открытый проект
- `LICENSE` (MIT), `CONTRIBUTING.md` для учеников (как устроен проект, как добавить функцию через тест, идеи задач), проверка в GitHub Actions, бесплатные варианты сервера в `docs/deploy.md`, README про учебный режим.

### Task 5. Проверка
- Полные тесты; e2e в учебном режиме — без единого ключа: вход по коду с экрана, оплата через страницу имитации.
