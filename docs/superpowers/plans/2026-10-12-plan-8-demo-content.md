# План 8. Наполнение учебного магазина — план реализации

> Выполняется по задачам, каждая через TDD: тест → падает → код → проходит → коммит.

**Goal:** После `scripts\setup.cmd` магазин выглядит живым: на витрине — полный каталог электроники с описаниями на двух языках, в админке — покупатели, заказы во всех статусах, возвраты, гарантийные случаи, отчёт продаж и переписка в «Имитации Telegram». Всё создаётся одной командой `seed_demo`.

**Решение (2026-10-12):** сервера пока нет — проект работает локально. Фотографий товаров нет и не будет (чужие фото нельзя класть в открытый репозиторий под MIT): витрина рисует силуэты устройств, для новых категорий добавляются свои силуэты.

## Global Constraints

Все ограничения Планов 1–7 действуют. Дополнительно:
- История магазина создаётся только через настоящие сервисы (`create_order`, `confirm_sourcing`, учебная оплата Payme/Click, `start_picking`, `add_unit`, `ship`, `deliver`, `open_return`/`inspect_return`/`refund_return`, `open_case`) — с `now` в прошлом. Никаких прямых записей статусов.
- `seed_demo` по-прежнему идемпотентна: повторный запуск ничего не дублирует. История создаётся один раз — если учебных покупателей ещё нет.
- Слаги и SKU, на которые опираются тесты и e2e (`iphone-16-pro`, `IP16P-256-BLK`, `galaxy-s25-ultra` и др.), не меняются; история не трогает свой склад `IP16P-256-BLK`, который покупает e2e.
- Данные каталога — отдельным модулем (`apps/core/demo_catalog.py`), команда — только логика.

## Задачи

### Task 1. Описание товара на витрине
- Карточка товара показывает `description_ru` / `description_uz` разделом «Описание» / «Tavsif», абзацы — по пустой строке. Пустое описание — раздела нет.

### Task 2. Новые виды товаров на витрине
- Силуэты для смарт-часов, защитных стёкол и внешних аккумуляторов.
- Названия и образцы цвета для новых значений: серебристый, золотой, оранжевый, фиолетовый, розовый, жёлтый; вид наушников: вкладыши / накладные.

### Task 3. Полный демо-каталог
- 8 категорий: смартфоны, планшеты, смарт-часы, наушники, чехлы, защитные стёкла, зарядные устройства, внешние аккумуляторы.
- Около 45 моделей Apple, Samsung, Xiaomi, Honor, Sony, JBL, Anker, Baseus, Ugreen, Spigen — с характеристиками, вариантами и описаниями ru/uz.
- Свой склад с IMEI, три поставщика (свежие и устаревшие прайсы), совместимость аксессуаров, подарки (чехлы, стёкла), правила наценки.
- Синонимы поиска для новых брендов и категорий.

### Task 4. История магазина
- Учебные покупатели с адресами (Ташкент и области), привязанные к учебным чатам Telegram.
- Около 30 заказов за последние полтора месяца во всех статусах: ждёт поставщика, ждёт оплаты, оплачен, собирается, у курьера, доставлен, завершён, отменён, возврат запрошен / проверен / деньги возвращены; оплата Payme и Click (оплата при получении в магазине ещё не реализована).
- Гарантийные случаи по проданным IMEI.
- В учебном режиме без токена события сразу доставляются в «Имитацию Telegram».

### Task 5. Проверка
- Полные тесты; e2e; пересоздать локальную базу и посмотреть витрину, админку, рабочее место оператора, отчёт и «Имитацию Telegram» на скриншотах.
